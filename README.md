# 學習打卡 App

一個可以安裝在手機主螢幕的「每日學習打卡」工具，依照你的每週回家學習計畫設計。

## 功能

- **今日**：顯示今天的學習計畫，完成一項就按「打卡」，會蓋上紅色印章、記錄時間；也可以臨時新增自訂項目；每張卡片都有「番茄鐘」可直接對該科目計時
- **番茄鐘**：專注／短休／長休三種模式（預設 25／5／15 分鐘，可自行調整），圓環倒數、完成自動切換並提示音，今日完成的番茄數會累計到統計頁；下方還有「播放音樂」，貼上 mp3 網址或 YouTube 連結即可邊學習邊聽
- **計畫**：查看完整的每週計畫（平日每天 2 小時、1–2 科；假日最多 5 小時）
- **統計**：連續完整達成天數、本週完成率、累計打卡次數、累計番茄數、本週每日進度長條圖
- **記錄**：歷史打卡紀錄（最近 90 天）
- 資料存在手機／電腦瀏覽器的本機（localStorage），不會上傳到任何伺服器

## 如何開始使用

### 方法一：電腦上直接看
用瀏覽器開啟 `index.html` 即可操作。

### 方法二：手機上使用（推薦）
1. 把整個資料夾放上 **GitHub Pages** 或任何靜態網站託管（Netlify、Vercel 等）
   - GitHub 步驟：把資料夾內容推到一個 repo → 在 repo 的 Settings → Pages → 選 Branch 部署 → 得到網址
2. 用手機瀏覽器打開該網址
3. 點瀏覽器選單 →「加入主螢幕」（Android 為「加到主畫面」／iPhone 為「加入主畫面」）
4. 手機桌面就會出現「學習打卡」圖示，點開像一般 App 一樣全螢幕使用，且離線可用

> 註：PWA 的「安裝到主螢幕」功能需要透過 https 網址開啟；如果只是本機打開 `index.html`，功能全部可用，只是不會出現安裝提示。

## 時間管理與學習計畫

- **平日（一～五）**：每天最多 2 小時、1–2 科，建議 18:30 開始，科目之間休息 10 分鐘；每科都有建議時段與建議番茄數（專注 25 分＋休息 5 分）
- **假日（六、日）**：每天最多 5 小時，分成上午、下午兩段；週六當週總複習、週日預習下週進度
- **原則**：21:30 前收工維持作息；先做當天課業複習，再做弱點補強
- 每張今日卡片與計畫頁都會顯示「建議時段」（如 18:30–19:30）與「約 N 個番茄」

## 修改計畫內容

所有學習計畫都定義在 `index.html` 的 `PLAN` 陣列（每個星期天數對應一天的科目、分鐘數、備註、建議時段 `slot`），直接改文字即可。
